## Незавершённый код, только WIP-ветка

Изменения ещё **не развёрнуты на Pi**; его stepik.env не переключён на Groq,
активный старый DAILY_TARGET остаётся 26. Service/timer бота остаются выключены.

- `groq_solver.py`: отдельный HTTPS-клиент, явная конфигурация провайдера,
  приватный key-file, строгий JSON и штатная validate_reply, Retry-After с
  ограниченным бюджетом, безопасные коды ошибок, числовые метрики использования.
- Structured Outputs используются без streaming: Groq не поддерживает их
  совместно. Локальный llama.cpp-клиент и его SSE сохранены.
- `configure_groq.py`: скрытый ввод на Pi, проверка ключа перед заменой,
  атомарные приватные файлы, сохранение строк OAuth, активация только после
  успешного GET модели. `--check-only` не меняет конфигурацию/Stepik.
- Добавлен явный LLM_PROVIDER=groq и необязательный LLM_PROXY_URL.

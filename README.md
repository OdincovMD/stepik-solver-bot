Бот для существующего `raspberry-llm` на Pi. Использует защищённый локальный
OpenAI-совместимый `/v1/chat/completions`, модель не переустанавливается.

Перед работой читать [docs/README.md](docs/README.md): текущие живые проверки,
OAuth только на Pi, чтение аккаунта → одна проба → малая серия, восстановление,
замеры и systemd. Таймер по умолчанию выключен.

Текущие результаты живой проверки аккаунта и пробы — в документации и приватных
отчётах на Pi. Дневной счётчик учитывает только новые подтверждённые полные решения;
искусственные задачи и результаты офлайн-тестов в него не входят.

В `raspberry-llm/` сохранены сопутствующие исходники локального inference-сервиса,
защищённого шлюза и документация его устройства. Веса и секреты остаются на Pi.

```bash
python3 -m unittest discover -s tests -q
python3 scripts/package.py
```
